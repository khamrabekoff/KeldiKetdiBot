# ✅ Pre-Deployment Checklist

Используйте этот чек-лист перед деплоем бота на PythonAnywhere.

## 🔒 Безопасность

- [ ] Получил новый токен бота в BotFather
- [ ] Старый токен отозван (`/revoke` в BotFather)
- [ ] `.env` файл создан и содержит все переменные
- [ ] `BOT_TOKEN` в `.env` - это новый токен
- [ ] `ADMIN_SECRET` сложный (минимум 16 символов, включает спецсимволы)
- [ ] `.env` файл **НЕ** загружен на GitHub (добавлен в .gitignore)
- [ ] `.env` файл **НЕ** случайно не закоммичен
- [ ] `WEBHOOK_DOMAIN` указан правильно (your-username.pythonanywhere.com)
- [ ] `WEBHOOK_URL` указан правильно (https://...)
- [ ] Все пути в конфиге используют `/home/username/...` формат

## 📁 Файлы

- [ ] В папке bot_v2 находятся все файлы:
  - [ ] config.py
  - [ ] database.py
  - [ ] messages.py
  - [ ] utils.py
  - [ ] app.py
  - [ ] wsgi.py
  - [ ] requirements.txt
  - [ ] .env (с секретами)
  - [ ] keldi_ketdi.db (старая БД, если переносим)
- [ ] Нет файлов `main.py` (он переименован в app.py)
- [ ] Нет файлов старого бота в той же папке

## 🚀 На PythonAnywhere

- [ ] Веб-приложение создано на PythonAnywhere
- [ ] Python версия 3.9+
- [ ] Все файлы загружены в /home/username/bot_v2/
- [ ] Виртуальное окружение создано
- [ ] Зависимости установлены (`pip install -r requirements.txt`)
- [ ] БД инициализирована (`python -c "import database; database.init_db()"`)
- [ ] WSGI конфиг обновлен (не старый конфиг из шаблона)
- [ ] Виртуальное окружение указано правильно в Web settings
- [ ] Все переменные окружения добавлены в Web app settings:
  - [ ] BOT_TOKEN
  - [ ] WEBHOOK_DOMAIN
  - [ ] WEBHOOK_URL
  - [ ] ADMIN_SECRET
  - [ ] DATABASE_PATH
  - [ ] FLASK_PORT
- [ ] Приложение перезагружено (зелёная кнопка Reload)
- [ ] Приложение online (status: "Site is online")

## 🌐 Webhook

- [ ] Webhook установлен в Telegram (выполнен скрипт из Step 3)
- [ ] Проверена информация о webhook через getWebhookInfo
- [ ] URL webhook точно совпадает с WEBHOOK_URL в конфиге
- [ ] Certificate не требуется (используется HTTPS)

## ✅ Тестирование

- [ ] Health check endpoint работает: https://username.pythonanywhere.com/health
- [ ] Можно отправить сообщение боту
- [ ] Бот запросил телефон на `/start`
- [ ] Можно отправить `/admin <SECRET_CODE>`
- [ ] Бот подтвердил что я администратор
- [ ] Меню работает
- [ ] Можно добавить сотрудника
- [ ] Можно отметить приход/уход
- [ ] Зарплата рассчитывается правильно

## 📊 Логи и Мониторинг

- [ ] Проверены логи на ошибки (Web > Log files)
- [ ] Нет ошибок при старте приложения
- [ ] Нет ошибок в error.log
- [ ] Все сообщения логируются правильно

## 📚 Документация

- [ ] Прочитал README.md
- [ ] Прочитал SETUP.md
- [ ] Понимаю как обновлять бота
- [ ] Знаю как делать бэкапы БД
- [ ] Знаю где смотреть логи при ошибках

## 🔄 Бэкап

- [ ] Сделан бэкап старой БД (если переносим)
- [ ] БД сохранена на безопасном месте
- [ ] Понимаю как восстановить БД из бэкапа
- [ ] Знаю команду для автоматического бэкапа

## ⚡ Оптимизация

- [ ] FLASK_PORT = 5000 (для бесплатного тарифа)
- [ ] Не используются job_queue задачи (они не работают на бесплатном)
- [ ] Не используется PicklePersistence (могут потеряться данные)
- [ ] Используется webhook вместо polling (экономит ресурсы)

## 🐛 Частые ошибки

Убедитесь что избежали этих ошибок:

- [ ] Не забыл обновить WSGI файл
- [ ] Не забыл обновить виртуальное окружение
- [ ] Не забыл установить зависимости
- [ ] Не забыл установить webhook в Telegram
- [ ] Не забыл перезагрузить приложение
- [ ] Не использую старый main.py (переименовано в app.py)
- [ ] Не оставил hardcoded BOT_TOKEN в конфиге

## 📞 После деплоя

- [ ] Бот работает стабильно (хотя бы час)
- [ ] Все функции работают как ожидается
- [ ] Логи не содержат ошибок
- [ ] Телефон администратора работает для тестирования
- [ ] Создано рабочее место для бэкапов
- [ ] Документировано где хранятся секреты
- [ ] Установлен мониторинг (проверка логов)

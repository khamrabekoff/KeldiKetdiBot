# 🤖 Keldi-Ketdi Bot v5.0 (Webhook Edition)

**Полностью переделанный и оптимизированный Telegram-бот для управления посещаемостью сотрудников**

## 🆕 Что изменилось

### ✅ Исправления безопасности
- ✔️ **Токен бота больше не в исходном коде** - используются переменные окружения
- ✔️ **Сложный пароль администратора** - вместо `admin2026`
- ✔️ **Нет SQL инъекций** - все запросы параметризированы
- ✔️ **Валидация всех входных данных** - проверка телефонов, времени, чисел

### 📡 Оптимизация для PythonAnywhere
- ✔️ **Webhook вместо polling** - работает на бесплатном тарифе
- ✔️ **Flask сервер** - современная архитектура
- ✔️ **Лучшая обработка ошибок** - логирование везде
- ✔️ **Готов к продакшену** - протестирован на стабильность

### 🎯 Улучшения функциональности
- ✔️ Исправлена опечатка в `EDIT_RATE_PER_MINUTE` (была `_minute`)
- ✔️ Все функции возвращают правильные значения
- ✔️ Лучшая обработка разных типов зарплаты
- ✔️ Улучшенный расчет wage для monthly и per_minute

- ✔️ Смотреть месячный отчёт

### Admin (Администратор)
- ✔️ Всё что есть у Employee
- ✔️ Смотреть кто пришёл сегодня
- ✔️ Смотреть месячный отчёт (Telegram или Excel)
- ✔️ Управлять сотрудниками (добавлять, удалять)
- ✔️ Изменять ставки сотрудников
- ✔️ Вручную редактировать время и зарплату
- ✔️ Рассматривать заявки на исправление

## 💰 Типы расчета зарплаты

### 1. Tariff (Тариф) - 4 периода
- 09:00 - 11:00: rate_n
- 11:00 - 16:00: rate_m
- 16:00 - 18:00: rate_k
- 18:00+ : rate_overtime

### 2. Monthly (Месячный оклад)
- Фиксированный месячный оклад
- Дополнительно: ставка за переработку

### 3. Per Minute (Поминутная)
- Плата за каждую минуту работы
